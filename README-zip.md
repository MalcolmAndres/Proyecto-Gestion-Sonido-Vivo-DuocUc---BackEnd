# Backend Sonido Vivo (ms-inventario y ms-catalogo)

- ms-inventario (puerto 8084): stock, reservas y movimientos
- ms-catalogo (puerto 8083): productos y categorías

Los pom.xml ya vienen listos (basados en el proyecto TCG, con MySQL en vez de Oracle).
Cada archivo .java vacío dice en qué paso de la guía se escribe.
Antes de partir: copiar mvnw, mvnw.cmd y .mvn/ del proyecto TCG dentro de cada servicio (Paso 0.1).
